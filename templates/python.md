## 环境

- Python <3.12>，依赖用 <uv / pip + requirements.txt> 管理
- 运行：`<uv run python main.py>`；测试：`<uv run pytest>`
- 不要往系统 Python 里装包；新依赖先问我，再写进依赖文件

## 约定

1. 函数加类型标注；脚本入口放在 `if __name__ == "__main__":` 里。
2. 路径用 `pathlib`，读写文件显式指定 `encoding="utf-8"`（Windows 下尤其重要）。
3. 配置和密钥从环境变量或 `.env` 读，不写死在代码里。
4. 处理大文件时流式读写，不要一次性读进内存。
5. 爬虫类任务遵守目标站点的 robots 和频率限制，加重试和超时。
6. 数据处理先在小样本上跑通，把样本结果给我看，再跑全量。

## 不要做

- 不要删除或覆盖 `data/` 下的原始数据，输出写到 `output/`。
- 不要为了「通用」加一堆用不上的参数和抽象。

## 完成标准

- 实际运行过一次，贴出关键输出；
- 有测试的话 `pytest` 全部通过。
